# Upstream grounding

Reviewed for this implementation on 2026-09-30. These projects informed the design; the SDK is not a compatibility layer for their extension binaries or packages.

| Source                                                                                      | What informed this SDK                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [VS Code activation events](https://code.visualstudio.com/api/references/activation-events) | Lazy activation, command contributions, activation/deactivation lifecycle.                                                                                                                           |
| [Zed extension development](https://zed.dev/docs/extensions/developing-extensions)          | Declarative metadata and explicit extension capabilities. Zed's Rust/WASM runtime was not copied into this TypeScript runtime.                                                                       |
| [Sublime Text API](https://www.sublimetext.com/docs/api_reference.html)                     | Straightforward commands and event listeners.                                                                                                                                                        |
| [ACP initialization](https://agentclientprotocol.com/protocol/v1/initialization)            | Version negotiation and truthful capability advertisement.                                                                                                                                           |
| [ACP session setup](https://agentclientprotocol.com/protocol/v1/session-setup)              | Initialization before sessions; separate session IDs and fixed working directory routing.                                                                                                            |
| [ACP prompt turns](https://agentclientprotocol.com/protocol/v1/prompt-turn)                 | Streamed updates, prompt responses, cancellation, and pending permission cancellation.                                                                                                               |
| [ACP tool calls](https://agentclientprotocol.com/protocol/v1/tool-calls)                    | Preserve tool updates and return selected/cancelled permission outcomes.                                                                                                                             |
| [Tauri capabilities](https://v2.tauri.app/security/capabilities/)                           | Distinguish window/webview/native capabilities from SDK extension grants.                                                                                                                            |
| [xterm flow control](https://xtermjs.org/docs/guides/flowcontrol/)                          | Bound buffering and leave backend flow control explicit.                                                                                                                                             |
| [Iris Agent](https://github.com/4onstudios/iris-agent)                                      | The GitHub page could not be retrieved in this environment. The published npm package at version 0.2.9 was inspected instead, including README, CLI, `IrisClient` declarations, and package exports. |

Compiled and checked against the published declarations for `monaco-editor@0.56.0`, `xterm@5.3.0`, and `@agentclientprotocol/sdk@1.4.0`. The ACP integration tests use that real SDK with an in-process test agent. Model credentials and a real Iris agent session were not used.

Inspected Iris package metadata: binary `iris-agent` maps to `dist/cli.js`; version 0.2.9 declares ACP SDK `^1.4.0`. CLI and README confirm `--workspace` and `--acp`. `IrisClient` declares `openSession`, `prompt`, `cancel`, `closeSession`, and `close`; its raw connection is private. The SDK therefore integrates through ACP, without importing Iris's private implementation modules.
